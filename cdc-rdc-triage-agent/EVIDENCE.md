# Evidence

Each capability claim is tied to the source that implements it, the test that
exercises it, and a command to reproduce. Run from the repo root in the venv.

Setup:

```bash
python3.13 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pip install -e ../rtl-intent-ingestor     # to regenerate manifests from RTL
```

## Golden inputs

`examples/*.sv` are public toy designs. The committed `examples/expected/*.manifest.json`
were generated by `rtl-intent-ingestor` from those `.sv` files; the
`examples/expected/*.report.json|md` and `tests/golden/*.report.json` are this
tool's output over those manifests.

Regenerate everything:

```bash
# manifests (requires rtl-intent-ingestor installed)
for f in cdc_sync rdc_example single_clock; do
  rtl-intent ingest examples/$f.sv -o examples/expected/$f.manifest.json
done
# reports + goldens
python tests/regenerate_golden.py
```

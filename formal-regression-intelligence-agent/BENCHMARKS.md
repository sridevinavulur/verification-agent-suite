# Benchmarks

## Bundled data

`examples/sample_ledger.jsonl` — a **synthetic public toy** run ledger of 20
records over 5 generic benchmark names (`counter`, `arbiter`, `fifo_overflow`,
`fifo_underflow`, `handshake`) and 4 generic config IDs. It is generated by
`scripts/make_fixtures.py`.

- **Source / license:** authored for this repository; public, MIT-licensed. No
  real telemetry, no proprietary designs, tools, hosts, or paths. Design/property
  SHAs are `sha256` of generic label strings.
- **Purpose:** it is hand-crafted so each of the 7 analyses fires at least once
  (see the docstring in `make_fixtures.py`). It is a *functional* fixture, not a
  performance benchmark.

## What is measured

This project reports **implementation correctness only**, via the golden-output
test and per-analysis behavior tests (see `EVIDENCE.md`). Specifically:

- The analysis reproduces `examples/golden_report.json` exactly.
- The golden exercises all `FindingKind` values.
- Each analysis fires on a designed positive and stays silent on a near-miss
  negative.

## What is NOT measured (exclusions)

- No claim about detection precision/recall on real regression telemetry.
- No claim about any formal tool's runtime, memory, or flakiness.
- No tuned thresholds; `analysis.Thresholds` defaults are chosen for clarity.

## Reproduce

```bash
pip install -e ".[dev]"
python scripts/make_fixtures.py      # regenerate ledger + golden
pytest -k golden                     # confirm the golden matches
```

# Evidence

Each resume-safe claim below is tied to source, a test, the benchmark input, and
a reproduce command. Distinguishes **implementation** evidence from
**experimental-performance** evidence. Release tag: `v0.1.0` (commit placeholder
`<SHA>`). Tool version: `perf-regression-agent 0.1.0`, Python ≥ 3.11.

Benchmark input: `examples/telemetry/benchmark.json` — synthetic public mock
telemetry, MIT-licensed, generated by `perf_regression_agent.benchmark.build_dataset`
(seed `20260920`). No proprietary data.

---

### CLAIM-1 — Detects the injected regression (implementation + experimental)

- **Text**: "Deterministically detects the two injected performance regressions
  (sim runtime +35%, peak memory +18%) in the public benchmark."
- **Source**: `detector.py::analyze`, `compare_pair`, `_classify`;
  `benchmark.py::build_dataset` (group A).
- **Tests**: `tests/test_detector.py::test_detects_exactly_the_injected_regressions`,
  `test_regression_has_direction_and_evidence`.
- **Reproduce**: `perf-regress demo` → `regressions=2`.
- **Expected**: `reports/golden_report.json` `n_regressions == 2`.

### CLAIM-2 — No false alarm on noise (implementation + experimental)

- **Text**: "Does not false-alarm on a pure-noise workload group."
- **Source**: `_classify` dual significance gate; `statistics.py`.
- **Test**: `tests/test_detector.py::test_no_false_alarm_on_noise_group`.
- **Reproduce**: `perf-regress show-report examples/telemetry/benchmark.json`
  (debug/smoke rows are `STABLE`).

### CLAIM-3 — Robust outlier rejection (implementation)

- **Text**: "A single wild sample does not create a false regression; outliers
  are rejected via IQR + modified z-score."
- **Source**: `statistics.py::reject_outliers`, `summarize`.
- **Tests**: `tests/test_statistics.py::test_reject_outliers_flags_wild_point`,
  `test_summarize_rejects_outlier_from_mean`,
  `tests/test_detector.py::test_fpga_outlier_does_not_cause_false_regression`.

- **Test**: `tests/test_detector.py::test_incomparable_runs_not_compared_across_platforms`.

## Provenance of the bundled Manifest

`examples/rtl/secure_soc.manifest.json` was generated by the sibling
`rtl-intent-ingestor` (`rtl-intent ingest`) from
`examples/rtl/secure_soc.sv`, i.e. it is a real product of the canonical
ingestor, not hand-written. It validates against
`rtl-intent-ingestor/schemas/manifest.schema.json`.

## Reproduce the full example run

```bash
security-property-agent run \
  examples/requirements/secure_soc.requirements.yaml \
  --manifest examples/rtl/secure_soc.manifest.json \
  --out report.json
# -> requirements=8 candidates=7 mutations=10 with_errors=0
```
